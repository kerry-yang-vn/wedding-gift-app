# 축의금 접수 앱 (태블릿 PWA)

결혼식 접수대에서 태블릿(아이패드 등)으로 쓰는 축의금·식권 기록 앱입니다. 서버 없이 기기 안에 저장되고, 한 번 열어두면 **인터넷이 없어도** 동작합니다.

## 기능

- **접수대 측 고정**: 처음 실행할 때 이 기기가 신랑측/신부측 중 어느 쪽인지 선택하면, 그 측의 내역·합계·CSV만 표시됩니다. 상대측 정보와 전체 합계는 어디에도 나오지 않습니다. 측 변경은 접수 내역을 모두 지운 뒤에만 가능합니다.
- 이름 입력 + 금액 버튼 `1만` `3만` `5만` `10만` **누적 합산** (예: 10만 + 5만 = 150,000원)
  - `마지막 취소`, `금액 초기화`로 오입력 정정
  - 4개 버튼 아래 `직접 입력`: 2만·25,000원처럼 버튼에 없는 금액을 숫자(원)로 입력해 같은 방식으로 더함 (Enter로도 추가, 1억 원 상한)
- 식권 **대인 / 소인** 각각 `−` / `+` (기본 0장씩)
- 상단 고정 합계: 해당 측의 총 인원 / 총 축의금 / 식권 발급 수(총합과 `대인 N · 소인 M`)
- 접수 내역: 최신순 목록, 이름 검색, **수정**, **삭제(7초 내 되돌리기)**
- **엑셀로 내보내기(.xlsx)**: 해당 측 데이터만 담기며 파일명에 측이 표시됩니다(`축의금_신랑측_20261104.xlsx`). 열은 `번호·구분·이름·축의금·식권 대인·식권 소인·식권 합계·접수시각`. 머리글 강조·천 단위 콤마·열 너비·첫 행 고정·필터가 적용되고, 맨 아래 합계 행은 SUM 수식이라 수정하면 자동 갱신됩니다. 공유 시트에서 "파일에 저장" / AirDrop / 메일 선택
- **엑셀 비밀번호 선택**: 내보내기를 누르면 `비밀번호 없이` / `비밀번호 걸기` 중 고릅니다. 비밀번호(4자 이상, 확인 입력, 보기 토글)를 정하면 엑셀 표준(Office Agile, AES-256)으로 파일 자체가 암호화되어, 엑셀·Numbers·LibreOffice에서 열 때 비밀번호를 물어봅니다. **비밀번호를 잊으면 복구할 수 없습니다.** 암호화는 1초 안팎이 걸리며, 끝나면 `저장·공유하기`를 한 번 더 누릅니다. 비밀번호 기능은 https(또는 설치된 앱)에서만 동작합니다.
- **CSV**: 보조 버튼. 비밀번호를 걸 수 없는 평문 파일이므로 주의. 엑셀 파일 저장이 막히는 환경에서 백업용으로 사용 (한글 안 깨짐)
- **전체 삭제**는 `삭제`를 직접 입력해야 실행 (실수 방지)
- **설치 안내 바**: 아이패드 Safari에서는 `설치 방법 보기`(홈 화면에 추가 3단계 안내), 크롬 등에서는 `앱 설치` 버튼 표시. 이미 설치해서 실행 중이면 나타나지 않음 (iOS는 Apple 정책상 버튼 한 번으로 자동 설치 불가)

## 태블릿에 설치하기

태블릿에서 오프라인 기능을 쓰려면 앱 파일을 **HTTPS 주소**에 올려야 합니다. (무료 호스팅 중 하나를 선택)

1. 이 폴더(`wedding-gift-app`)를 GitHub Pages, Cloudflare Pages, Netlify Drop 중 한 곳에 올립니다.
2. 아이패드는 **Safari**로 해당 주소를 엽니다.
3. 공유 버튼(□↑) → **홈 화면에 추가**.
4. 홈 화면 아이콘으로 실행하면 전체 화면 앱처럼 열립니다.

> 행사 전날, **Wi-Fi가 되는 곳에서 홈 화면 앱을 한 번 열어** 오프라인 캐시를 만들어 두세요. 이후에는 인터넷 없이 동작합니다.

## 데이터 보관 안내

- 데이터는 **그 기기의 앱 안에만** 저장됩니다. 다른 기기와 동기화되지 않으므로, 신랑측·신부측 기기는 같은 주소로 설치해도 서로의 데이터를 볼 수 없습니다.
- 각 기기에서 처음 실행할 때 반드시 자기 측을 선택하세요. 잘못 골랐다면 접수 내역이 비어 있을 때 `측 변경`으로 바꿀 수 있습니다.
- Safari 웹사이트 데이터 삭제, 앱 아이콘 삭제 시 데이터가 사라집니다.
- 행사 중간(예: 식 시작 전)과 종료 직후에 **CSV 내보내기**로 백업해 두세요.
- 사생활 보호 모드에서는 저장이 안 될 수 있습니다. 이 경우 화면 상단에 경고가 표시됩니다.

## 개발 / 테스트

```bash
npm test          # 핵심 로직 유닛 테스트 (Node 20+, 추가 설치 없음)
npm install       # UI 테스트용 jsdom 설치 (최초 1회)
npm run test:ui   # 화면 조작 시나리오 테스트
npm run serve     # 로컬 확인: http://localhost:8080
```

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `logic.js` | 금액 합산·검증·집계·CSV·엑셀용 시트 모델·저장 복원 (화면과 무관한 순수 함수) |
| `xlsx.js` | 외부 라이브러리 없는 .xlsx 생성기 (ZIP + SpreadsheetML), 오프라인 동작 |
| `officecrypto.js` | 엑셀 비밀번호 암호화 (Office Agile: SHA-512 키 파생 + AES-256-CBC + HMAC, CFB 컨테이너), 외부 라이브러리 없음 |
| `app.js` | 화면 렌더링, 버튼 이벤트, localStorage 연동 |
| `index.html` | 화면 구조와 스타일 |
| `sw.js` | 오프라인 캐시 (앱 파일을 수정해 재배포할 때는 `CACHE` 버전 번호를 올릴 것) |
| `manifest.webmanifest`, `*.png` | 홈 화면 설치용 설정과 아이콘 |
| `test/`, `tests-ui/` | 유닛 테스트 / UI 시나리오 테스트 |
