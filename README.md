# 축의금 접수 앱 (아이패드 PWA)

결혼식 접수대에서 아이패드로 쓰는 축의금·식권 기록 앱입니다. 서버 없이 기기 안에 저장되고, 한 번 열어두면 **인터넷이 없어도** 동작합니다.

## 기능

- **신랑측 / 신부측** 선택 (선택한 측은 다음 접수에도 유지)
- 이름 입력 + 금액 버튼 `1만` `3만` `5만` `10만` **누적 합산** (예: 10만 + 5만 = 150,000원)
  - `마지막 취소`, `금액 초기화`로 오입력 정정
- 식권 `−` / `+` (기본 0장)
- 상단 고정 합계: 총 인원 / 총 축의금 / 식권 발급 수 + 신랑측·신부측 각각의 집계
- 접수 내역: 최신순 목록, 이름 검색, 측별 필터, **수정**, **삭제(7초 내 되돌리기)**
- **CSV 내보내기**: 아이패드 공유 시트에서 "파일에 저장" / AirDrop / 메일 선택 (엑셀에서 한글 안 깨짐)
- **전체 삭제**는 `삭제`를 직접 입력해야 실행 (실수 방지)

## 아이패드에 설치하기

아이패드에서 오프라인 기능을 쓰려면 앱 파일을 **HTTPS 주소**에 올려야 합니다. (무료 호스팅 중 하나를 선택)

1. 이 폴더(`wedding-gift-app`)를 GitHub Pages, Cloudflare Pages, Netlify Drop 중 한 곳에 올립니다.
2. 아이패드 **Safari**로 해당 주소를 엽니다.
3. 공유 버튼(□↑) → **홈 화면에 추가**.
4. 홈 화면 아이콘으로 실행하면 전체 화면 앱처럼 열립니다.

> 행사 전날, **Wi-Fi가 되는 곳에서 홈 화면 앱을 한 번 열어** 오프라인 캐시를 만들어 두세요. 이후에는 인터넷 없이 동작합니다.

## 데이터 보관 안내

- 데이터는 **그 아이패드의 앱 안에만** 저장됩니다. 다른 기기와 동기화되지 않습니다.
- Safari 웹사이트 데이터 삭제, 앱 아이콘 삭제 시 데이터가 사라집니다.
- 행사 중간(예: 식 시작 전)과 종료 직후에 **CSV 내보내기**로 백업해 두세요.
- 사생활 보호 모드에서는 저장이 안 될 수 있습니다. 이 경우 화면 상단에 경고가 표시됩니다.

## 개발 / 테스트

```bash
npm test          # 핵심 로직 유닛 테스트 (Node 20+, 추가 설치 없음)
npm install       # UI 테스트용 jsdom 설치 (최초 1회)
npm run test:ui   # 화면 조작 시나리오 테스트
npm run serve     # 로컬 확인: http://localhost:8080
```

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `logic.js` | 금액 합산·검증·집계·CSV·저장 복원 (화면과 무관한 순수 함수) |
| `app.js` | 화면 렌더링, 버튼 이벤트, localStorage 연동 |
| `index.html` | 화면 구조와 스타일 |
| `sw.js` | 오프라인 캐시 (앱 파일을 수정해 재배포할 때는 `CACHE` 버전 번호를 올릴 것) |
| `manifest.webmanifest`, `*.png` | 홈 화면 설치용 설정과 아이콘 |
| `test/`, `tests-ui/` | 유닛 테스트 / UI 시나리오 테스트 |
